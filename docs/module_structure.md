# Module Structure

This module follows `dephy_module_golden_sample` with an additional web profile
directory:

- `include/dephy_web/`: public metadata API
- `src/`: portable metadata implementation
- `products/`: product web asset profiles
- `tools/`: web embed tooling
- `tests/`: Linux unit tests
- `zephyr/`: Zephyr module metadata
- `scripts/`: local test scripts
